    Your diet plan

    Upload a custom diet JSON. Each user gets their own — syncs across devices when signed in.

    How this works Your diet (meals, batch tasks, shopping lists, macro targets) is stored as a JSON file. Upload one to replace the default. Your trainer can send you a new file anytime — just upload it.

    Current diet

    JSON structure

    What the diet file should contain

    • name — Display name of the diet (e.g. "Veg High-Protein")
    • goals — Daily macro targets {cal, pro, car, fat}
    • meals — Array of meal slots with options, macros, ingredients, steps
    • batchTasks — Per-day batch cooking tasks (sun/wed/sat etc)
    • weeklyShop — Perishables shopping list, categorized
    • monthlyShop — Pantry shopping list, categorized

    Download the current diet to see a working example of the exact structure expected.
